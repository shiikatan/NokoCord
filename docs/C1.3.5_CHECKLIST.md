# NokoCord Chiaki C1.3.5 Checklist

This is the executable checklist for the C1.3.5 confidence-and-recovery
release. Every checked item needs test output, a manual validation note, or an
explicit external-host exception. Generated packages, private session state,
recovery material, reports, and agent notes remain outside tracked source.

## Evidence record — 2026-09-29

- `sh scripts/build.sh` passed and produced Chiaki C1.3.5 build 7. The native
  verifier passed signature, entitlement, architecture, callback, privacy and
  reviewed-helper checks.
- `python3 scripts/test_release_metadata.py` passed 7 tests; parity passed 9
  tests; Broker passed 9 tests; the translator suite passed 11 tests; the Tan
  fixture suite passed 4 tests; `swiftc -typecheck
  Tools/NokoMusicWatch/main.swift` passed; and `plutil -lint
  NokoCord.xcodeproj/project.pbxproj` passed.
- `sh scripts/package-release.sh` passed against the signed CLI artifact; the
  ZIP contained exactly the 15 reviewed files, its C1.3.5 build 7 metadata
  matched the canonical config, and the recorded SHA-256 matched the ZIP.
- `swift test --scratch-path /private/tmp/NokoCord-tests` reaches test
  compilation but is blocked because this host's Command Line Tools do not
  provide XCTest. `sh scripts/verify.sh` stops earlier with the actionable
  missing/non-executable `xcstringstool` diagnostic, and `xcodebuild` confirms
  that full Xcode is not selected. These are explicit external-host gates, not
  passing claims.
- Live calls, Apple Music Automation, sleep/wake, VoiceOver, long-session
  performance and fresh-Xcode artifact checks remain manual or full-Xcode
  gates. The maintainer authorized the C1.3.5 tag, Chiaki branch push and
  GitHub Release publication on 2026-09-29 after this evidence review.

## 0. Release control

- [x] Work only on `chiaki`.
- [x] Do not synchronize Maomao or `noko`.
- [x] Preserve the one persistent Discord WKWebView invariant.
- [x] Preserve Discord ownership of authentication, messages, media, and
      account state.
- [x] Add no raw-token, credential, cookie, CEF, broker-client, self-bot,
      marketplace, second-WebView, or native Discord call transport.
- [x] Read current `AGENTS.md` before each implementation slice.
- [x] Keep workstream write sets disjoint and review every returned diff.
- [x] Keep generated artifacts, private state, and agent notes untracked.

- [x] Model bounded probe facts, feature states, sanitized reasons, route, and
      document generation.
- [x] Probe navigation, messages, composer, media, calls, notifications, and

      degraded.
- [x] Label hashed-class fallbacks and test semantic-selector drift.
- [x] Cover `/app` and `/channels/*`, login, settings, OAuth, invite, error,

- [x] Cover Zen/reload generation synchronization and stale probe callbacks.
- [x] Add Compatibility Center status, recovery action, accessibility labels,
      and redacted diagnostics.
- [x] Add deterministic 1,000-message and 1,000-editor mutation budgets

## 2. Tan trust and recovery UX

- [x] Persist target, capabilities, trust origin, enabled state, health,
      failure category/time, approved hash, last-known-good hash, and one

- [x] Migrate older trust records safely without granting new trust.
- [x] Enforce package and translated-archive quotas.
- [x] Categorize helper callback failures without raw error retention.
- [x] Show hash/target/capability/origin diffs before re-approval.
- [x] Show failure category/time and accurate page-world trust warnings.

- [x] Confirm every trust-changing, restore, disable, and Safe Mode action.
- [x] Prove wrong origin/hash/nonce/capability/payload/rate/frame requests are
      rejected and all resources clean up (XCTest execution is an
      external-host gate).
- [x] Prove one failed Tan does not stop unrelated Tans (XCTest execution is an
      external-host gate).

## 3. Calls and Apple Music

- [x] Model call leave-requested, Discord-leave-confirmed, capture-cleared,
      and blocked-navigation states.
- [x] Scope disconnect to the active call surface and cover distractor controls.
- [x] Do not clear native call state before the Discord leave postcondition and
      capture `.none` are observed.
- [x] Cover permission denial/recovery, minimize/reopen, sleep/wake, and stale
      generation behavior in the focused contracts; live lifecycle execution
      remains a manual gate.
- [ ] Run the two-user, ten-minute live-call gate.
- [x] Cover Apple Music cold start, pause/resume, stop, seek, repeat, next,
      quit/relaunch, identity changes, delayed events, and helper disconnect.
- [x] Enforce one helper, bounded retry/backoff, heartbeat/stale detection, and
      exit after NokoCord quits.
- [x] Keep missing/denied/unsupported/stale and notification-only fallback
      labels truthful.
- [x] Do not advertise exact-position support before a signed-build manual gate.
- [x] Keep hardened runtime/sandbox posture unchanged unless a separate
      security decision is approved.
