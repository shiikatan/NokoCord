# NokoCord Chiaki C1.3.0 Release Checklist

This is the executable checklist for C1.3.0. Every checked item needs either
test evidence, a manual validation note, or an explicit release exception.
Generated packages, private state and agent notes stay outside tracked source.

## 0. Release control

- [x] Confirm checkout is `chiaki`.
- [x] Confirm no Maomao or `noko` branch synchronization is part of the work.
- [x] Confirm the maintainer-approved scope is the C1.3.0 design document.
- [x] Confirm no raw-user-token transport, credential extraction, CEF or broker
      production path has been added.
- [x] Confirm the one-persistent-WKWebView invariant remains intact.
- [x] Confirm current `AGENTS.md` has been read before each implementation
      slice.
- [x] Confirm each implementation slice has a named owner and disjoint write
      set.
- [x] Confirm generated reports, local packages, credentials, recovery
      material and agent notes are ignored and untracked.
