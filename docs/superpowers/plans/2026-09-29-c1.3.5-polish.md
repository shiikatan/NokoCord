# C1.3.5 Performance and Accessibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use red-green-refactor; measure behavior with deterministic fixtures before changing observers or Tan markup.

**Goal:** Make long-session DOM work bounded and make Focus Shield and Code Workbench usable with keyboard, VoiceOver, and reduced motion.

**Architecture:** Keep one delegated observer per relevant Tan with explicit scan budgets. Treat accessibility state as part of the Tan lifecycle: activation adds labelled controls and focus behavior, cleanup removes every owned node/listener/style, and reduced-motion switches transitions off.

**Tech Stack:** Swift 6, injected JavaScript/CSS, WebKit fixtures, XCTest.

**Spec:** `docs/superpowers/specs/2026-09-29-c1.3.5-design.md`

## Global Constraints

- Focus Shield and Code Workbench remain capability-free.
- No fetch, persistence, code execution, clipboard native bridge, or account mutation.
- Editor mutations cannot trigger unrelated message/media scans.
- Every observer, timer, listener, style, and mount has deterministic cleanup.
